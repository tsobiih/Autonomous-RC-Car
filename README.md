# 🚗 Autonomous RC Car Project  

This project features a **self-navigating RC car** powered by an **ATmega32 microcontroller**. It supports both **manual mode (Bluetooth control)** and **autonomous mode (obstacle avoidance)** using ultrasonic and IR sensors.

## 🛠 Hardware Components  
- **Microcontroller:** ATmega32  
- **Sensors:** Ultrasonic & IR for obstacle detection  
- **Motor Driver:** L298N  
- **Communication:** Bluetooth (HC-05)  
- **Power Supply:** Li-ion battery  
- **Chassis:** [Custom 3D Design on GrabCAD](https://grabcad.com/library/rc-car-107)  

## 🔧 Software & Tools  
- **Programming:** Embedded C (C language)  
- **Development Environment:** Eclipse IDE, Proteus for simulation  
- **Design Software:** Autodesk Inventor  

## 📂 Project Structure  
- **`src/`** → Contains all source code files (`.c`, `.h`).  
- **`proteus/`** → Contains simulation files (`.dsn`, `.lyt`).  
- **`media/`** → Includes images, videos, and PDFs.
